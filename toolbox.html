⭐ Tool of the Month

This month's featured pick, plus a prompt to help you get more out of it.

Microsoft 365 Copilot
Copilot Agents: build an AI helper around the work you do repeatedly.
Open M365 →

Go beyond one-off prompts. You may already use Microsoft 365 Copilot to summarise documents, draft emails or find information. Copilot Agents take this a step further. You can use Microsoft’s ready-made agents for particular types of work, or create your own agent with instructions and selected knowledge sources so it can support a recurring task in a more consistent way.

Think of it as moving from “help me with this task” to “here’s how I usually do this task.”

What can you do with Copilot Agents?

🔎

Choose a ready-made specialist

Microsoft-built agents such as Researcher and Analyst are designed for more focused tasks, from investigating a topic to analysing information across files.

🛠️

Build an agent for your own work

With Agent Builder, you can create one by starting from a template, describing what you want in plain language, or configuring it yourself.

📚

Give it relevant knowledge

Configure knowledge sources so the agent works with information relevant to the job rather than relying only on what you explain in each prompt. Sources can include SharePoint, OneDrive, email and websites.

📋

Set instructions once

Tell the agent the task, how it should approach it and what kind of output you want. Useful for a recurring role or process where you would otherwise keep repeating similar instructions.

Quick rule of thumb: don’t build an agent just because you can. If a normal Copilot Chat prompt gets the job done, start there. Agent Builder makes more sense when you need repeatable instructions, selected knowledge and consistent behaviour.

🎯 Prompt of the Month

Turn a recurring task into your own Copilot Agent

1. Pick a repeatable task

A good starting point is something where:

  • you do roughly the same task each time;
  • you regularly refer to the same sources; and
  • you usually follow similar steps or produce a similar output.

2. Open Agent Builder

In Microsoft 365 Copilot, go to Agents and select Create agent / New agent. Agent Builder is available from the Agents area of Microsoft 365 Copilot.

3. Tell Agent Builder what you want

Copy, paste and customise this:

I want to create an agent that supports my work. The agent should help me with [DESCRIBE YOUR RECURRING TASK], using the reference materials and information I provide.

For each task, the agent should:

  1. Review the information – Examine the relevant documents, emails, meeting notes, spreadsheets or other materials I provide.
  2. Extract what matters – Identify key information relating to [TOPICS / AREAS TO LOOK OUT FOR].
  3. Organise the findings – Group related information and highlight important updates, outstanding matters, deadlines, risks, dependencies or decisions required.
  4. Identify gaps – Flag missing, inconsistent or unclear information. Do not make assumptions or invent details to fill gaps.
  5. Prepare the output – Produce a [OUTPUT FORMAT, e.g. briefing note, summary table, email draft or progress update] for [INTENDED AUDIENCE].
  6. Keep it appropriate – Use a [TONE] tone and a [LEVEL OF DETAIL] level of detail. Keep the output clear, concise and easy to act on.

Use only the information available in the materials provided or sources I have specifically made available. Where possible, indicate which source supports key findings so I can verify them. Do not make policy interpretations, commitments or decisions on my behalf. Flag matters that require my review.

If the task or expected output is unclear, ask me for clarification before proceeding.

Customise the prompt: Replace the bracketed sections with details of your own recurring task. You can also add specific instructions, preferred output formats or examples of past work to help the agent produce more consistent results.

4. Test before relying on it

Try the agent against a task you already know well. Check whether it:

  • picks up the right information;
  • follows your requested structure;
  • flags gaps rather than filling them in; and
  • produces something you would actually use.

Then refine its instructions.
